Frequently Asked Questions

Are these image tools free?

Yes. The tools on this page are available to use without a paid subscription. Your device handles most processing.

Which image formats are supported?

Static image tools support JPG, PNG and WebP. GIF Studio supports animated GIF creation, optimization and frame extraction.

Does image compression always reduce file size?

Not always. The result depends on the original image, output format and selected quality. Compare the original and processed sizes before using the result.
